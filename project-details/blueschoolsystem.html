Hệ thống quản lý đào tạo BlueSchoolSystem

Chi tiết dự án

Vai trò: Trưởng nhóm

Dẫn dắt đội ngũ xây dựng hệ sinh thái quản lý đào tạo đa nền tảng bao gồm Web Admin và Mobile App. Điểm nổi bật là tích hợp AI nhận diện khuôn mặt để chống gian lận điểm danh. Đồ án xuất sắc đạt điểm tuyệt đối 10/10.

Nhiệm vụ chính:

  • Lên kế hoạch kiến trúc hệ thống và phân công công việc trong nhóm.
  • Phát triển Web Admin quản lý lớp học, sinh viên, giảng viên và lịch dạy.
  • Tích hợp module AI nhận diện khuôn mặt (face-recognition) vào quy trình điểm danh để ngăn chặn gian lận.
  • Xây dựng Mobile App (Flutter) kết nối với backend qua RESTful API.
  • Thiết kế và tối ưu schema cơ sở dữ liệu SQL Server cho toàn hệ thống.

Công nghệ: ASP.NET Core, Flutter, Dart, SQL Server, Python (face-recognition), RESTful API, Entity Framework Core.

Kết quả & chỉ số: Đồ án đạt điểm tuyệt đối 10/10; hệ thống AI chống gian lận hoạt động ổn định với độ chính xác nhận diện cao trong môi trường thử nghiệm thực tế.
