SPACEGO E-Commerce Website

Chi tiết dự án

Vai trò: Web Developer (ASP.NET MVC)

Nhiệm vụ chính:

  • Phát triển hệ thống quản lý sản phẩm, giỏ hàng và đơn hàng bằng ASP.NET MVC.
  • Thiết kế schema SQL Server, triển khai stored procedures và tối ưu query.
  • Đảm bảo responsive front-end và tích hợp gateway thanh toán (sandbox) cho thử nghiệm.

Công nghệ: ASP.NET MVC, C#, SQL Server, jQuery, Bootstrap.

Kết quả & chỉ số: Hoàn thiện MVP trong 10 tuần; chức năng đặt hàng và thanh toán mô phỏng hoạt động ổn định; chuẩn hoá API giúp giảm 30% thời gian phát triển tính năng mới.
