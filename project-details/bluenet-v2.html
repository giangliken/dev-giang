Ứng dụng BlueNet-V2

Chi tiết dự án

Vai trò: Trưởng nhóm

Thiết kế và phát triển nền tảng quản lý học tập tích hợp đa năng, tối ưu hóa quy trình tương tác dữ liệu giữa sinh viên và giảng viên thông qua hệ thống RESTful API hiệu suất cao. Đồ án hoàn hảo đạt 10/10.

Nhiệm vụ chính:

  • Thiết kế kiến trúc tổng thể hệ thống và xây dựng RESTful API chuẩn hóa cho toàn bộ module.
  • Phát triển backend xử lý các nghiệp vụ quản lý lớp học, bài tập, điểm số và thông báo.
  • Xây dựng Mobile App Flutter kết nối và đồng bộ dữ liệu real-time với server.
  • Tối ưu hóa truy vấn SQL Server, giảm thiểu độ trễ phản hồi API xuống mức tối thiểu.
  • Viết tài liệu API và hướng dẫn tích hợp cho các thành viên trong nhóm.

Công nghệ: ASP.NET Core, Flutter, Dart, SQL Server, Entity Framework Core, RESTful API, JWT Authentication.

Kết quả & chỉ số: Đồ án đạt điểm tuyệt đối 10/10; API response time tối ưu dưới 200ms cho 95% các request; hệ thống hỗ trợ đồng thời nhiều lớp học và người dùng trong môi trường thử nghiệm.
