Debounce và Throttle: Tối ưu Performance

Kiểm soát tần suất thực thi hàm để cải thiện hiệu năng ứng dụng.

Khi làm việc với các DOM event như scroll, resize, hay keyup, hàm xử lý có thể được gọi hàng trăm lần mỗi giây, gây ra các vấn đề về hiệu năng. Debounce và Throttle là hai kỹ thuật giúp giải quyết vấn đề này.

Debounce

Debounce sẽ trì hoãn việc thực thi một hàm cho đến khi đã qua một khoảng thời gian nhất định mà không có lần gọi mới nào. Nó rất hữu ích cho các tác vụ như auto-suggest, nơi bạn chỉ muốn thực hiện tìm kiếm sau khi người dùng đã ngừng gõ.

function debounce(func, delay) {
  let timeoutId;
  
  return function(...args) {
    clearTimeout(timeoutId);
    timeoutId = setTimeout(() => {
      func.apply(this, args);
    }, delay);
  };
}

// Sử dụng:
const expensiveOperation = () => console.log('Thực hiện tác vụ tốn kém...');
const debouncedOperation = debounce(expensiveOperation, 500);

window.addEventListener('keyup', debouncedOperation);
// Hàm chỉ được gọi 500ms sau khi người dùng ngừng gõ.

Throttle

Throttle đảm bảo một hàm chỉ được thực thi tối đa một lần trong một khoảng thời gian nhất định. Nó phù hợp cho các event liên tục như scroll hoặc resize, nơi bạn muốn cập nhật giao diện một cách mượt mà mà không bị quá tải.

function throttle(func, limit) {
  let inThrottle = false;
  
  return function(...args) {
    if (!inThrottle) {
      func.apply(this, args);
      inThrottle = true;
      setTimeout(() => {
        inThrottle = false;
      }, limit);
    }
  };
}

// Sử dụng:
const onScroll = () => console.log('Đang scroll...');
const throttledScroll = throttle(onScroll, 200);

window.addEventListener('scroll', throttledScroll);
// Hàm `onScroll` chỉ được gọi tối đa 1 lần mỗi 200ms.

Tóm lại, hãy dùng Debounce khi bạn muốn thực thi hàm sau khi một chuỗi sự kiện kết thúc, và dùng Throttle khi bạn muốn giới hạn tần suất thực thi của một hàm trong một chuỗi sự kiện.
