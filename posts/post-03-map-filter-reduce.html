Sử dụng `Map`, `Filter`, `Reduce` hiệu quả

Làm chủ các phương thức mảng để viết code ngắn gọn và dễ hiểu.

map, filter, và reduce là các phương thức bậc cao (higher-order functions) giúp xử lý mảng một cách khai báo (declarative) thay vì mệnh lệnh (imperative) với các vòng lặp for.

1. `map()`

map() tạo ra một mảng mới bằng cách áp dụng một hàm lên mỗi phần tử của mảng ban đầu. Nó hữu ích khi bạn muốn biến đổi dữ liệu.

const numbers = [1, 2, 3, 4, 5];
// Trả về một mảng mới với mỗi số được nhân đôi
const doubled = numbers.map(num => num * 2);

console.log(doubled); // [2, 4, 6, 8, 10]
console.log(numbers); // [1, 2, 3, 4, 5] (mảng gốc không đổi)

2. `filter()`

filter() tạo ra một mảng mới chứa tất cả các phần tử của mảng ban đầu vượt qua một bài kiểm tra (trả về true).

const numbers = [1, 2, 3, 4, 5, 6];
// Trả về mảng mới chỉ chứa các số chẵn
const evenNumbers = numbers.filter(num => num % 2 === 0);

console.log(evenNumbers); // [2, 4, 6]

3. `reduce()`

reduce() thực thi một hàm "reducer" trên mỗi phần tử của mảng, từ đó trả về một giá trị duy nhất. Đây là phương thức linh hoạt nhất.

Ví dụ, để tính tổng một mảng:

const numbers = [1, 2, 3, 4, 5];
// `accumulator` là giá trị tích lũy, `currentValue` là phần tử hiện tại
const sum = numbers.reduce((accumulator, currentValue) => {
  return accumulator + currentValue;
}, 0); // 0 là giá trị ban đầu của accumulator

console.log(sum); // 15

Kết hợp chúng

Sức mạnh thực sự bộc lộ khi bạn kết hợp các phương thức này. Ví dụ: tính tổng bình phương của các số lẻ.

const numbers = [1, 2, 3, 4, 5];

const sumOfOddSquares = numbers
  .filter(num => num % 2 !== 0) // [1, 3, 5]
  .map(num => num * num)      // [1, 9, 25]
  .reduce((sum, square) => sum + square, 0); // 1 + 9 + 25 = 35

console.log(sumOfOddSquares); // 35
