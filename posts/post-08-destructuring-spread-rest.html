Destructuring và Spread/Rest Operators

Những cú pháp ES6 giúp bạn làm việc với object và array hiệu quả hơn.

1. Destructuring Assignment

Destructuring cho phép bạn "giải nén" các giá trị từ mảng hoặc thuộc tính từ đối tượng vào các biến riêng biệt.

Với Object

const developer = {
  firstName: 'Giang',
  lastName: 'Nguyen',
  language: 'JavaScript'
};

// Trích xuất thuộc tính vào các biến cùng tên
const { firstName, language } = developer;
console.log(firstName); // 'Giang'
console.log(language); // 'JavaScript'

// Đổi tên biến
const { firstName: fName, lastName: lName } = developer;
console.log(fName); // 'Giang'

Với Array

const skills = ['C#', 'Flutter', 'SQL', 'Dart'];

const [primary, secondary] = skills;
console.log(primary); // 'C#'
console.log(secondary); // 'Flutter'

2. Spread Operator (`...`)

Toán tử Spread cho phép một iterable (như mảng hoặc chuỗi) được "mở rộng" thành các phần tử riêng lẻ. Nó thường được dùng để sao chép hoặc hợp nhất mảng và đối tượng.

// Hợp nhất mảng
const backend = ['C#', '.NET'];
const frontend = ['React', 'Vue'];
const fullstack = [...backend, ...frontend];
console.log(fullstack); // ['C#', '.NET', 'React', 'Vue']

// Sao chép đối tượng
const person = { name: 'Giang', age: 25 };
const personClone = { ...person };
console.log(personClone); // { name: 'Giang', age: 25 }

3. Rest Parameter (`...`)

Mặc dù có cùng cú pháp, Rest Parameter thực hiện nhiệm vụ ngược lại với Spread. Nó thu thập nhiều phần tử và "gói" chúng vào một mảng. Nó rất hữu ích khi làm việc với các hàm có số lượng tham số không xác định.

function sum(...numbers) {
  // `numbers` là một mảng chứa tất cả các đối số được truyền vào
  return numbers.reduce((total, num) => total + num, 0);
}

console.log(sum(1, 2, 3)); // 6
console.log(sum(10, 20, 30, 40, 50)); // 150

Kết hợp với destructuring, bạn có thể lấy ra các phần tử đầu và gom phần còn lại.

const languages = ['JavaScript', 'Python', 'Go', 'Rust', 'C++'];

const [main, secondary, ...others] = languages;
console.log(main);      // 'JavaScript'
console.log(secondary); // 'Python'
console.log(others);    // ['Go', 'Rust', 'C++']
