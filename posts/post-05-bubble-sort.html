Giải thuật Sắp xếp Nổi bọt (Bubble Sort)

Một thuật toán sắp xếp đơn giản để bắt đầu hành trình học giải thuật.

Sắp xếp nổi bọt là một thuật toán sắp xếp đơn giản, hoạt động bằng cách lặp lại việc duyệt qua danh sách, so sánh các phần tử liền kề và hoán đổi chúng nếu chúng sai thứ tự. Quá trình này được lặp lại cho đến khi không cần hoán đổi nữa, nghĩa là danh sách đã được sắp xếp.

Ý tưởng

Tên "nổi bọt" xuất phát từ việc các phần tử nhỏ hơn (hoặc lớn hơn) dần dần "nổi" lên đầu danh sách, giống như những bọt khí trong nước.

Triển khai bằng JavaScript

Dưới đây là cách triển khai thuật toán Bubble Sort trong JavaScript.

function bubbleSort(arr) {
  const n = arr.length;
  let swapped;

  do {
    swapped = false;
    for (let i = 0; i < n - 1; i++) {
      // So sánh cặp liền kề
      if (arr[i] > arr[i + 1]) {
        // Hoán đổi vị trí nếu sai thứ tự
        [arr[i], arr[i + 1]] = [arr[i + 1], arr[i]];
        swapped = true;
      }
    }
  } while (swapped); // Lặp lại nếu trong lần duyệt vừa rồi có hoán đổi

  return arr;
}

// Sử dụng:
const unsortedArray = [64, 34, 25, 12, 22, 11, 90];
const sortedArray = bubbleSort(unsortedArray.slice()); // Dùng slice() để không thay đổi mảng gốc

console.log('Mảng đã sắp xếp:', sortedArray);
// Mảng đã sắp xếp: [11, 12, 22, 25, 34, 64, 90]

Độ phức tạp

Bubble Sort có độ phức tạp thời gian trong trường hợp xấu nhất và trung bình là O(n²), làm cho nó không hiệu quả trên các danh sách lớn. Tuy nhiên, nó là một thuật toán tuyệt vời để tìm hiểu các khái niệm cơ bản về sắp xếp.
