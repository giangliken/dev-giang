Proxy và Reflection trong JavaScript

Can thiệp và tùy chỉnh hành vi mặc định của đối tượng.

ES6 giới thiệu hai tính năng siêu lập trình (metaprogramming) mạnh mẽ: Proxy và Reflection. Chúng cho phép bạn can thiệp (intercept) và định nghĩa lại các hành vi cơ bản của một đối tượng.

Proxy Object

Một đối tượng Proxy bao bọc một đối tượng khác (gọi là target) và cho phép bạn định nghĩa các "bẫy" (traps) để can thiệp vào các hoạt động cơ bản trên target. Ví dụ: đọc thuộc tính, gán giá trị, gọi hàm...

Cú pháp: const proxy = new Proxy(target, handler);

  • target: Đối tượng gốc cần bao bọc.
  • handler: Một đối tượng chứa các hàm "trap" để can thiệp.

Ví dụ: Validation với `set` trap

Chúng ta có thể dùng Proxy để kiểm tra dữ liệu trước khi gán giá trị cho một thuộc tính.

const user = {
  age: 25
};

const userValidator = {
  set: function(target, property, value) {
    if (property === 'age') {
      if (!Number.isInteger(value) || value <= 0) {
        throw new TypeError('Tuổi phải là một số nguyên dương.');
      }
    }
    // Gán giá trị nếu hợp lệ
    target[property] = value;
    return true; // Bắt buộc trả về true khi thành công
  }
};

const userProxy = new Proxy(user, userValidator);

userProxy.age = 26; // Hợp lệ
console.log(userProxy.age); // 26

try {
  userProxy.age = 'hai sáu'; // Sẽ throw TypeError
} catch (e) {
  console.error(e.message); // "Tuổi phải là một số nguyên dương."
}

Reflection (API `Reflect`)

Reflect là một đối tượng tích hợp cung cấp các phương thức tương ứng với các "trap" của Proxy. Các phương thức của Reflect có cùng tên với các trap. Ví dụ: Reflect.get(), Reflect.set(), Reflect.has().

Lợi ích chính của Reflect là nó cung cấp một cách mặc định để thực hiện các hành vi gốc bên trong một trap của Proxy. Điều này giúp code sạch sẽ và dễ bảo trì hơn.

Ví dụ: Kết hợp Proxy và Reflect

Sử dụng Reflect.set bên trong trap set để thực hiện hành vi gán giá trị mặc định.

const user = {};

const loggingHandler = {
  set: function(target, property, value) {
    console.log(`Gán giá trị: ${property} = ${JSON.stringify(value)}`);
    // Dùng Reflect.set để thực hiện hành vi mặc định
    return Reflect.set(target, property, value);
  }
};

const loggingProxy = new Proxy(user, loggingHandler);

loggingProxy.name = 'Giang'; 
// Output: "Gán giá trị: name = "Giang""
loggingProxy.skills = ['JS', 'C#']; 
// Output: "Gán giá trị: skills = ["JS","C#"]"

Proxy và Reflect mở ra nhiều khả năng cho các thư viện và framework, ví dụ như trong các hệ thống state management (Vue.js 3), ORM, hoặc để tạo các API linh hoạt.
