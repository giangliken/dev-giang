Hiểu Sâu về `this` trong JavaScript

Khám phá cách từ khóa this hoạt động trong các ngữ cảnh khác nhau.

Từ khóa this trong JavaScript là một trong những khái niệm dễ gây nhầm lẫn nhất. Giá trị của this được xác định bởi cách một hàm được gọi (ngữ cảnh thực thi). Dưới đây là các quy tắc chính.

1. Global Scope

Trong ngữ cảnh toàn cục (global scope), this tham chiếu đến đối tượng global, là window trong trình duyệt.

console.log(this === window); // true

2. Function Context

Bên trong một hàm thông thường, this cũng tham chiếu đến đối tượng global. Tuy nhiên, trong 'strict mode', giá trị của this sẽ là undefined.

function showThis() {
  'use strict';
  console.log(this); // undefined
}
showThis();

3. Method Context

Khi một hàm được gọi như một phương thức của một đối tượng, this sẽ tham chiếu đến chính đối tượng đó.

const person = {
  name: 'Giang',
  greet: function() {
    console.log(`Hello, my name is ${this.name}`);
  }
};

person.greet(); // "Hello, my name is Giang"

4. Arrow Functions

Arrow functions không có ngữ cảnh this của riêng nó. Thay vào đó, nó kế thừa this từ ngữ cảnh (lexical scope) mà nó được định nghĩa.

const developer = {
  name: 'Dev Giang',
  skills: ['JS', 'C#', 'Flutter'],
  showSkills: function() {
    this.skills.forEach(skill => {
      // `this` ở đây là `developer` object
      console.log(`${this.name} knows ${skill}`);
    });
  }
};

developer.showSkills();

Đây là một ưu điểm lớn khi làm việc với các callback hoặc hàm lồng nhau, giúp tránh việc phải dùng .bind(this) hoặc const self = this;.
