Closures và Scope Chain

Hiểu cách các hàm "ghi nhớ" môi trường nơi chúng được tạo ra.

Scope Chain là gì?

Khi một hàm được thực thi, JavaScript tạo ra một ngữ cảnh thực thi. Nếu một biến không được tìm thấy trong scope hiện tại, nó sẽ tìm kiếm ở scope cha, rồi đến scope ông, và cứ thế tiếp tục cho đến khi đến global scope. Chuỗi tìm kiếm này được gọi là Scope Chain.

Closure là gì?

Một closure là sự kết hợp của một hàm và môi trường từ vựng (lexical environment) mà hàm đó được khai báo. Nói cách khác, một hàm "ghi nhớ" tất cả các biến có sẵn tại nơi nó được định nghĩa, ngay cả khi nó được thực thi ở một nơi khác.

Đây là một khái niệm mạnh mẽ và là nền tảng cho nhiều mẫu thiết kế trong JavaScript.

function createGreeting(greeting) {
  // `greeting` là một phần của lexical environment của hàm bên trong
  return function(name) {
    // Hàm này là một closure. Nó "nhớ" biến `greeting`.
    console.log(`${greeting}, ${name}!`);
  };
}

// Tạo một hàm chuyên để chào "Hello"
const sayHello = createGreeting('Hello');

// Tạo một hàm chuyên để chào "Hi"
const sayHi = createGreeting('Hi');

sayHello('Giang'); // "Hello, Giang!"
sayHi('Dev');    // "Hi, Dev!"

Trong ví dụ trên, hàm được trả về từ createGreeting là một closure. Nó có quyền truy cập vào biến greeting của hàm cha ngay cả sau khi hàm createGreeting đã thực thi xong.

Một ví dụ kinh điển

Closures thường được dùng để tạo các biến riêng tư (private variables).

function createCounter() {
  let count = 0; // Biến này là 'private'

  return {
    increment: function() {
      count++;
    },
    decrement: function() {
      count--;
    },
    getCount: function() {
      return count;
    }
  };
}

const counter = createCounter();
counter.increment();
counter.increment();
console.log(counter.getCount()); // 2

console.log(counter.count); // undefined (không thể truy cập trực tiếp)

Ở đây, biến count không thể được truy cập từ bên ngoài, nhưng các phương thức bên trong closure có thể đọc và ghi nó. Đây là một cách để tạo ra state ẩn trong JavaScript.
